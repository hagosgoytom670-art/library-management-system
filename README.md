# 📚 Library Management System

A web-based Library Management System developed to simplify and automate library operations, including book management, borrowing and returning, reservations, student management, course materials, fines, and notifications.

## 🚀 Features

### 👨‍🎓 Student
- Student registration and login
- Browse available books
- Search for books
- Borrow and return books
- View borrowing history
- Book reservations
- View fines and payment history
- Download course materials
- Profile management

### 📚 Librarian
- Add and manage books
- Issue books to students
- Process returned books
- Manage reservations
- Check student borrowing records
- Manage librarian schedules
- Generate library reports
- Send email notifications

### 👨‍💼 Administrator
- Manage students
- Manage librarians
- Manage system users
- Upload course materials
- Manage library information
- Generate reports
- View system activities
